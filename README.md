# 물멍

[kenzie.kr/water](https://kenzie.kr/water/) — 시점을 움직이며 바라보는 청록빛 바다.

HTML 안에서 Three.js / WebGL2로 실시간 렌더링합니다. 영상 재생이나 사진 전체를 휘게 하는 효과는 사용하지 않습니다.

## 실행

Node.js 18 이상이 필요합니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:4173/water/ 를 엽니다. 시작할 때 번들을 빌드합니다. 소스를 수정한 뒤 `npm run build`로 다시 빌드하고 새로고침합니다.

## 장면

- `seabed.js`: 고정된 128×128m 굴곡 지형, 바위 158개, 자갈 480개. 큰 바위는 비대칭 절단면을 가진 석회암 형태입니다. 사진의 그림자를 요철로 사용하지 않고, 정적인 광물 얼룩과 미세 입자를 적용합니다. 바위의 위치·형상·텍스처 좌표는 시간에 따라 변하지 않습니다.
- `wave-field.js`: 서로 다른 방향과 위상의 파도 42개를 7개 파장 대역으로 합성합니다. 고정 수심 4m의 분산 관계로 속도를 구하고, 잔잔한 관찰 장면에 맞춰 기울기와 재생 속도를 조정합니다. 실제 지형 수심에 따라 파도가 변하는 시뮬레이션이나 특정 해역의 측정 데이터는 아닙니다.
- `ocean.js`: 512×512 GPU 텍스처에 계산한 높이와 기울기를 실제 64×64m 수면 메시와 물리 재질에서 공유합니다. 큰 너울은 메시 높이를 바꾸고, 작은 잔물결은 표면 법선을 바꿉니다. 멀리 있는 미세 물결은 밉맵과 기울기 분산을 이용해 부드러운 반사로 전환하므로 깜빡임을 줄입니다.
- `underwater.js`와 `ocean.js`: 수면을 숨긴 장면의 선형 색상과 깊이를 별도 타깃에 렌더링합니다. 굴절률 1.333으로 굴절 방향을 구하고 화면에 잡힌 깊이를 제한된 횟수로 탐색해 광로 길이와 색 흡수를 추정합니다. 물리 재질의 하늘·태양 반사는 유지하되 Three의 기본 transmission은 꺼서 투과 패스를 중복 생성하지 않습니다. 톤매핑과 화면 색 변환은 최종 출력에 적용합니다.
- 화면 밖이나 바위 실루엣에서 교차점을 신뢰할 수 없으면 원래 화면 좌표의 샘플로 돌아갑니다. 화면공간 굴절은 가려진 뒷면이나 화면 밖 장면을 복원할 수 없으며 완전한 광선 추적은 아닙니다.
- `caustics.js`: 같은 파장 필드의 법선으로 수중 빛의 모임과 퍼짐을 부드럽게 근사합니다. 기준 수심의 평면에 만든 조명장을 고정된 바닥·바위 위치에 투영하며, 전체 광경로를 계산하는 물리 시뮬레이션은 아닙니다. 바위 형상과 질감은 움직이지 않습니다.
- `water.js`: 원근 카메라, 조명, 하늘 반사, 조작과 렌더링 생명주기. 화면 가로·세로의 1.18배 영역까지 렌더링해 굴절에 필요한 여백을 확보하고, 픽셀 예산은 실제 보이는 영역을 기준으로 정합니다. 초광폭 화면에서는 수평 화각을 제한해 지형 경계가 드러나지 않게 합니다.
- `assets/seabed.png`: 참고 사진을 바탕으로 imagegen으로 재구성한 정적 바닥 질감. 바닥과 바위의 재질에만 사용합니다. 원본 참고 사진은 배포에서 제외합니다.

## 조작

- 드래그 / 한 손가락: 시점 회전
- 휠 / 두 손가락 벌리기: 확대·축소
- 바다에 키보드 포커스 후 방향키: 시점 회전, `+` / `-`: 거리 조절, `Home`: 시점 초기화
- 오른쪽 아래: 화질 선택, 시점 초기화, 소리, 물결 정지, 전체 화면

화질은 자동·고화질·절전 중 선택합니다. 자동은 입력 장치와 화면 크기에 따른 정적 프리셋으로, 실시간 GPU 부하 적응은 포함하지 않습니다. 보이는 영역의 픽셀 예산은 자동에서 데스크톱 280만·터치 환경 140만, 고화질 500만, 절전 110만입니다. 기기 픽셀 비율과 프리셋 상한에 따라 실제 해상도는 이보다 낮을 수 있으며, 자동 터치 환경과 절전에서는 굴절 타깃도 줄입니다.

조작 아이콘은 약 2.6초 후 사라집니다. 포인터 이동, 터치, 키보드 입력으로 다시 나타나며 키보드 포커스 중에는 유지됩니다. 파도를 멈춰도 시점은 움직일 수 있습니다. 동작 줄이기 설정에서는 정지 상태로 시작합니다. 물소리는 클릭 후 시작하는 Web Audio 합성음입니다.

숨겨진 탭에서는 렌더링을 건너뛰고, 정지 상태에서는 시점·화질·화면 크기 등이 바뀔 때 다시 그립니다. 시간이 같으면 파장·카스틱 필드는 재사용합니다. 바위·자갈에는 인스턴싱을 사용합니다. WebGL2를 사용할 수 없으면 정적 질감을 표시합니다. 그래픽 컨텍스트가 복구되면 정지 중에도 파장·카스틱·수중 타깃·하늘 반사·그림자를 다시 생성합니다.

## 검증

`npm run check`는 JavaScript 구문을, `npm test`는 Node에서 생성 필드와 렌더 패스의 생명주기를 검사합니다. 실제 GPU 셰이더와 화면 품질은 브라우저에서 별도로 확인해야 합니다.

로컬 주소에 `?inspect`를 붙이면 `window.__waterDebug`를 사용할 수 있습니다. `snapshot()`은 렌더 통계, `setTime()`·`setView()`는 재현 가능한 정지 시점, `setCaustics()`는 조명 비교, `loseContext()`·`restoreContext()`는 복구 확인용입니다. `localhost`·`127.0.0.1`에서만 활성화됩니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다. 사용자 Pages 사이트의 `kenzie.kr` 도메인을 상속하므로 별도 CNAME은 필요하지 않습니다.

배포 전 `npm run check`, `npm test`, `npm run build`를 실행하고 생성된 `app.js`를 소스와 함께 커밋합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 실행 중 외부 CDN이나 영상 서버에 의존하지 않습니다.

다른 정적 호스팅에는 `index.html`, `style.css`, `app.js`, `assets/seabed.png`, `THIRD_PARTY_LICENSES.txt`를 배치합니다. URL은 모두 상대 경로입니다. Three.js 라이선스는 `THIRD_PARTY_LICENSES.txt`에 포함되어 있습니다.
