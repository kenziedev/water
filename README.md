# 물멍

[kenzie.kr/water](https://kenzie.kr/water/) — 맑은 얕은 바다, 잔물결과 가끔 찾아오는 작은 물고기.

Three.js / WebGL2로 실시간 렌더링합니다. 기본은 움직임이 약한 **편안하게** 모드입니다. 카메라는 조작하지 않으면 고정됩니다.

## 실행

Node.js 18 이상이 필요합니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:4173/water/ 를 엽니다. 시작할 때 번들을 빌드합니다. 소스 수정 후 `npm run build`를 실행하고 새로고침합니다.

## 조작

- 드래그 / 한 손가락: 시점 회전
- 휠 / 두 손가락 벌리기: 확대·축소
- 바다에 키보드 포커스 후 방향키: 시점 회전, `+` / `-`: 거리 조절, `Home`: 처음 시점
- 오른쪽 아래: 물결 움직임, 화질, 시점 초기화, 물소리, 장면 정지, 전체 화면

일반 시점 이동은 약 0.12–0.16초 안에 안정되고, 처음 시점 복귀는 약 0.9초입니다. 새 조작은 현재 보이는 위치에서 복귀 동작을 중단합니다. 시점에 자동 흔들림·회전은 없습니다.

‘편안하게’는 바닥의 굴절 왜곡과 반짝임을 낮추고 물결을 느리게 재생합니다. ‘자연스럽게’는 조금 더 선명한 반사와 물결을 보여줍니다. 모드를 바꿔도 파도 시간이 초기화되지 않습니다. 기기의 ‘동작 줄이기’ 설정은 시작 시와 실행 중 모두 반영하며, 활성화되면 장면을 멈추고 카메라 보간을 끕니다. 설정을 해제해도 사용자가 재생할 때까지 정지를 유지합니다.

장면 정지는 물결·수초·물고기·등장 시간을 함께 멈춥니다. 정지 중에도 시점과 화질을 바꿀 수 있습니다. 물소리는 별도로 켜고 끕니다. 아이콘은 약 2.6초 뒤 사라지며, 포인터·터치·키보드 입력으로 다시 나타납니다. 키보드 포커스 중에는 유지됩니다.

## 물과 바닥

- `seabed.js`: 고정된 128×128m 굴곡 지형, 바위 158개, 자갈 480개. 실제 바위 형상에 따른 보수적인 장애물 경계를 생태 모듈과 공유합니다. 지형과 질감 좌표는 시간에 따라 움직이지 않습니다.
- `wave-field.js`: 7개 파장 대역의 방향성 파도 42개를 512×512 GPU 필드에 합성합니다. 높이·기울기·기울기 분산을 수면과 조명이 공유하며, 멀리 있는 미세 물결은 밉맵을 통해 반짝임을 부드럽게 합니다. 고정 수심에 따른 분산 관계를 사용한 연출이며 실제 해역 시뮬레이션은 아닙니다.
- `underwater.js` / `ocean.js`: 수중 장면의 선형 색상과 깊이를 별도 타깃에 렌더링합니다. 실제 깊이를 기준으로 색 흡수와 잔물결 변위를 계산하되, 평평한 수면과 기울어진 수면의 굴절 차이만 반영해 평균 바닥 위치를 안정시킵니다. 고정 위치의 깊이 비교로 바위 가장자리의 변위를 억제하고 색상은 한 번만 샘플링합니다. 굴절 경로 탐색의 교차점 전환에 따른 이중상·출렁임을 줄이기 위한 근사입니다. 완전한 광선 추적이나 정확한 평수면 굴절은 아니며, 아주 얇은 경계에는 화면공간 방식의 한계가 있습니다.
- 물리 재질의 하늘·태양 반사는 유지합니다. Three의 기본 transmission은 꺼서 투과 패스를 중복 생성하지 않으며, 톤매핑과 화면 색 변환은 최종 출력에 적용합니다.
- `caustics.js`: 같은 파장 필드로 수중 빛의 모임과 퍼짐을 부드럽게 근사해 고정 바닥 위치에 투영합니다. ‘편안하게’에서는 강도를 낮춥니다. 전체 광경로 계산은 아닙니다.
- `assets/seabed.png`: 참고 사진을 바탕으로 imagegen으로 재구성한 정적 바닥 질감. 바닥과 바위 재질에 사용하며 원본 참고 사진은 배포에서 제외합니다.

## 수초와 물고기

`flow.js`, `habitat.js`, `vegetation.js`, `ambient-events.js`, `fauna.js`, `ecology.js`가 고정 서식지와 드문 방문을 구성합니다.

수초는 바닥에 뿌리를 고정한 인스턴스 리본으로, 같은 느린 흐름을 따라 끝부분이 흔들립니다. 가운데 관찰 공간을 비워두고 바위와 겹치는 뿌리를 피합니다. 양면 불투명 재질을 사용합니다.

물고기는 작은 한 종류로 보통 1–3마리, 드물게 3–6마리가 방문합니다. 중앙 관찰 구간은 약 15–30초이며 그 사이 120–180초의 간격을 둡니다. 첫 중앙 도착은 30–55초 범위입니다. 이 시간은 중앙 통과 구간 기준이며 실제 화면에 보이는 시간은 시점과 화면비에 따라 달라집니다. 접근·퇴장은 이보다 긴 시간 동안 바깥쪽에서 이루어집니다. 경로와 등장은 장면 시간으로 결정되므로 일시정지·탭 전환·화질 변경이 새로운 물고기를 생성하지 않습니다. 물고기는 수면과 바닥 사이를 지나며 바위 장애물을 피합니다. 이는 시각 연출용 경로와 흐름이며 생물·유체 시뮬레이션은 아닙니다.

## 성능과 생명주기

- 자동 화질은 프레임 간격을 관찰해 3단계로 조절합니다. 일시적인 지연에는 반응하지 않고, 지속적으로 느리면 낮추며 안정적인 구간이 충분히 길어야 올립니다. 프레임 간격은 GPU 처리 시간 자체를 측정한 값이 아닙니다.
- 보이는 영역의 최대 픽셀 예산: 자동 데스크톱 280만→180만→110만, 터치 환경 140만→100만→70만. 고화질 500만, 절전 110만. 기기 픽셀 비율과 상한에 따라 실제 해상도는 더 낮을 수 있습니다.
- 낮은 단계에서는 수중 타깃 해상도와 수초 밀도를 줄입니다. 서식지 위치·물고기 경로·등장 시간은 유지합니다. 수면 주변 여백을 위해 화면 가로·세로의 1.18배를 렌더링하며 초광폭에서는 수평 화각을 제한합니다.
- 숨겨진 탭에서는 렌더링과 장면 시간을 멈춥니다. 정지 상태에서는 시점·화질·화면 크기 등이 바뀔 때만 다시 그리며, 시간이 같으면 파장·카스틱 필드를 재사용합니다.
- 바위·자갈·수초는 인스턴싱합니다. 움직이는 생물 때문에 전체 그림자 맵을 매번 다시 만들지 않습니다.
- 물소리는 클릭 후 생성하는 Web Audio 합성음입니다. 서로 다른 길이의 두 음원층과 느린 변조로 짧은 반복감을 줄이고 켜기·끄기에 페이드를 적용합니다. 숨겨진 탭에서는 오디오도 멈추고, 소리를 끄면 페이드 후 오디오 처리를 중단합니다.
- WebGL2를 사용할 수 없으면 정적 질감을 표시합니다. 그래픽 컨텍스트 복구 시 정지 중에도 필드·수중 타깃·하늘 반사·그림자를 다시 그립니다.

## 검증

```sh
npm run check
npm test
npm run build
```

구문 검사와 Node 테스트는 렌더 타깃 생명주기, 굴절 투영, 60/120Hz 카메라 일치·중단, 화질 조절의 지연·복구, 서식지·생물 경로를 검사합니다. 실제 셰이더와 화면 품질은 브라우저에서 별도로 확인합니다. 반응형 화면 검증은 실제 iOS·Android 기기에서의 발열·GPU 성능 검증을 대신하지 않습니다.

로컬 주소에 `?inspect`를 붙이면 `window.__waterDebug`를 사용할 수 있습니다. `snapshot()`은 장면·생물 상태와 렌더 통계, `setTime()`·`setView()`는 재현 가능한 정지 시점, `setSurface()`·`setCaustics()`는 수면·조명 비교, `loseContext()`·`restoreContext()`는 복구 확인용입니다. `localhost`·`127.0.0.1`에서만 활성화됩니다.

## 배포

GitHub Pages가 `main` 브랜치 루트(`/`)를 게시합니다. 사용자 Pages 사이트의 `kenzie.kr` 도메인을 상속하므로 별도 CNAME은 필요하지 않습니다. 기능 브랜치에 푸시하는 것만으로 운영 화면이 바뀌지는 않습니다.

검증 후 생성된 `app.js`를 소스와 함께 커밋합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 다른 정적 호스팅에는 `index.html`, `style.css`, `app.js`, `assets/seabed.png`, `THIRD_PARTY_LICENSES.txt`를 배치합니다. URL은 모두 상대 경로이며 실행 중 외부 CDN·영상·오디오 서버에 의존하지 않습니다. Three.js 라이선스는 `THIRD_PARTY_LICENSES.txt`에 포함되어 있습니다.
