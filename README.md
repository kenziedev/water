# 물멍

[kenzie.kr/water](https://kenzie.kr/water/) — 깊고 투명한 지중해의 수면을 바라보는 전체 화면 웹사이트.

## 실행

Node.js 18 이상에서 `npm run dev` 후 http://127.0.0.1:4173/water/ 를 엽니다. `npm run check`로 JavaScript 구문을 검사합니다. 외부 패키지 설치는 필요하지 않습니다.

## 렌더링

- `assets/seabed.png`: 사용자가 제공한 참고 사진을 바탕으로 imagegen으로 물결과 반사를 제거해 재구성한 바닥 이미지입니다. 원본 참고 사진은 로컬에 보존하고 배포에서는 제외합니다.
- `ocean.js`: 바닥 이미지 좌표는 시간과 무관하게 고정되어 있습니다. 바위 전체를 휘거나 옮기는 텍스처 변형은 없습니다.
- 수면은 서로 다른 방향·파장·속도의 24개 짧은 파동을 불규칙한 묶음으로 합성합니다. 증폭하지 않은 프레넬 반사를 선형 색 공간에서 혼합하고, 큰 물결에만 약한 밝기 변화를 적용합니다. 하얀 구름 반사 무늬나 넓은 빛 번짐은 사용하지 않습니다. 바위의 위치는 그대로 두고 그 위의 조명과 반사만 변합니다.
- 실제 촬영 영상이나 완전한 유체 시뮬레이션은 아닙니다. 외부 이미지·폰트·라이브러리 서비스에 의존하지 않습니다.

## 조작과 접근성

문구와 패널 없이 물만 보여줍니다. 오른쪽 아래 소리·일시정지·전체 화면 아이콘은 약 2.6초 후 사라집니다. 포인터 이동, 화면 터치, 키보드 입력으로 다시 표시됩니다. 키보드 포커스가 있으면 버튼이 유지됩니다. 동작 줄이기 설정에서는 정지 상태로 시작합니다. WebGL 초기화 실패나 컨텍스트 유실 시 바닥 정적 이미지를 표시합니다. 정지 상태와 숨겨진 탭에서는 수면을 다시 그리지 않습니다. 물소리는 사용자 클릭 후 시작하는 브라우저 합성음입니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 사용자 Pages 사이트의 커스텀 도메인 `kenzie.kr`을 상속하므로 이 저장소에는 별도의 CNAME을 추가하지 않습니다. 배포 주소는 `https://kenzie.kr/water/`입니다.

다른 정적 호스팅에서는 `index.html`, `style.css`, `water.js`, `ocean.js`, `assets/seabed.png`를 함께 배치합니다. 파일과 모듈 URL은 모두 상대 경로입니다.
