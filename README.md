# 물멍

[kenzie.kr/water](https://kenzie.kr/water/) — 시점을 움직이며 바라보는 청록빛 바다.

HTML 안에서 Three.js / WebGL2로 실시간 렌더링합니다. 영상 재생이나 사진 전체를 휘게 하는 효과는 사용하지 않습니다.

## 실행

Node.js 18 이상이 필요합니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:4173/water/ 를 엽니다. 시작할 때 번들을 빌드합니다. 소스를 수정한 뒤 `npm run build`로 다시 빌드하고 새로고침합니다. `npm run check`는 소스의 JavaScript 구문을 검사합니다.

## 장면

- `seabed.js`: 고정된 128×128m 굴곡 지형, 바위 158개, 자갈 480개. 큰 바위는 비대칭 절단면을 가진 석회암 형태입니다. 사진의 그림자를 요철로 사용하지 않고, 정적인 광물 얼룩과 미세 입자를 적용합니다. 바위의 위치·형상·텍스처 좌표는 시간에 따라 변하지 않습니다.
- `wave-field.js`: 서로 다른 방향과 위상의 파도 42개를 7개 파장 대역으로 합성합니다. 수심에 따른 분산 관계로 속도를 구하고, 큰 파도보다 작은 물결에 기울기 변화를 더 배분해 매끈한 반사 띠를 줄입니다. 이 분포는 참고 사진에 맞춘 시각적 조정이며 특정 해역의 측정 데이터는 아닙니다.
- `ocean.js`: 512×512 GPU 텍스처에 계산한 높이와 기울기를 실제 64×64m 수면 메시와 물리 재질에서 공유합니다. 큰 너울은 메시 높이를 바꾸고, 작은 잔물결은 표면 법선을 바꿉니다. 멀리 있는 미세 물결은 밉맵과 기울기 분산을 이용해 부드러운 반사로 전환하므로 깜빡임을 줄입니다.
- 물은 굴절률 1.333, 프레넬 반사, 투과와 색 흡수를 사용하는 물리 재질입니다. 바위 자체는 고정되어 있고, 수면의 굴절 때문에 물을 통해 보이는 모습이 달라집니다. 굴절 거리는 일정한 두께로 근사하며 완전한 유체 시뮬레이션이나 바닥 교차점을 추적하는 레이 트레이싱은 아닙니다.
- `water.js`: 원근 카메라, 조명, 하늘 반사, 조작과 렌더링 생명주기. 화면 바깥 여유 영역까지 렌더링해 굴절의 가장자리 늘어짐을 방지합니다. 초광폭 화면에서는 수평 화각을 제한해 지형 경계가 드러나지 않게 합니다.
- `assets/seabed.png`: 참고 사진을 바탕으로 imagegen으로 재구성한 정적 바닥 질감. 바닥과 바위의 재질에만 사용합니다. 원본 참고 사진은 배포에서 제외합니다.

## 조작

- 드래그 / 한 손가락: 시점 회전
- 휠 / 두 손가락 벌리기: 확대·축소
- 바다에 키보드 포커스 후 방향키: 시점 회전, `+` / `-`: 거리 조절, `Home`: 시점 초기화
- 오른쪽 아래: 시점 초기화, 소리, 물결 정지, 전체 화면

조작 아이콘은 약 2.6초 후 사라집니다. 포인터 이동, 터치, 키보드 입력으로 다시 나타나며 키보드 포커스 중에는 유지됩니다. 파도를 멈춰도 시점은 움직일 수 있습니다. 동작 줄이기 설정에서는 정지 상태로 시작합니다. 물소리는 클릭 후 시작하는 Web Audio 합성음입니다.

숨겨진 탭에서는 렌더링을 건너뛰고, 정지 상태에서는 카메라가 움직일 때만 다시 그립니다. 픽셀 수를 제한하고 바위·자갈에는 인스턴싱을 사용합니다. WebGL2를 사용할 수 없으면 정적 질감을 표시합니다. 그래픽 컨텍스트가 복구되면 하늘 반사와 그림자도 다시 생성합니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 게시합니다. 사용자 Pages 사이트의 `kenzie.kr` 도메인을 상속하므로 별도 CNAME은 필요하지 않습니다.

배포 전 `npm run check`와 `npm run build`를 실행하고 생성된 `app.js`를 소스와 함께 커밋합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 실행 중 외부 CDN이나 영상 서버에 의존하지 않습니다.

다른 정적 호스팅에는 `index.html`, `style.css`, `app.js`, `assets/seabed.png`, `THIRD_PARTY_LICENSES.txt`를 배치합니다. URL은 모두 상대 경로입니다. Three.js 라이선스는 `THIRD_PARTY_LICENSES.txt`에 포함되어 있습니다.
