# 물멍

[kenzie.kr/water](https://kenzie.kr/water/) — 투명한 바다의 실제 출렁임을 보는 전체 화면 페이지입니다.

## 실행

Node.js 18 이상에서 `npm run dev` 후 http://127.0.0.1:4173/water/ 를 엽니다. `npm run check`로 JavaScript 구문을 검사합니다. 외부 패키지 설치는 필요하지 않습니다.

## 바다 영상

바닥 사진을 움직이는 합성 효과 대신 실제 바다 촬영 영상을 사용합니다. 물결과 수면 반사, 물 아래 바위의 굴절이 촬영된 그대로 재생됩니다. 카메라 구도가 유지되는 장면을 골랐으며, 약 33초 영상의 앞뒤를 1초간 겹쳐 반복 지점의 급격한 전환을 줄였습니다. 화질과 초기 로딩 속도를 고려해 H.264 MP4로 재인코딩하고, 메타데이터를 파일 앞으로 배치했습니다.

소스와 사용 조건은 [영상 출처](assets/CREDITS.md)에 기록되어 있습니다. 실행 중 외부 영상 서비스에 연결하지 않고 저장소의 MP4를 직접 제공합니다. 원본 영상과 인코딩 도구는 Git에서 제외합니다.

## 조작

화면 문구 없이 영상만 보여줍니다. 오른쪽 아래 소리·일시정지·전체 화면 아이콘은 약 2.6초 후 사라지고, 포인터 이동·터치·키보드 입력으로 다시 표시됩니다. 키보드 포커스가 있으면 버튼이 유지됩니다.

영상은 기본적으로 무음 자동 재생됩니다. 동작 줄이기 설정이 켜져 있거나 자동 재생이 차단되면 재생 버튼을 표시합니다. 숨겨진 탭에서는 영상을 멈추고, 돌아왔을 때 이전에 재생 중이었던 경우에만 이어갑니다. 물소리는 별도 버튼을 누르면 시작하는 합성음이며 촬영 영상의 현장음은 아닙니다.

## 배포

GitHub Pages의 `main` 브랜치 루트(`/`)를 게시합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 사용자 Pages의 도메인 `kenzie.kr`을 상속하므로 별도 CNAME은 사용하지 않습니다.

정적 호스팅에 필요한 파일은 `index.html`, `style.css`, `water.js`, `assets/ocean.mp4`, `assets/ocean-poster.jpg`입니다. 로컬 서버도 영상 탐색과 반복 재생에 필요한 HTTP Range 요청을 지원합니다.
